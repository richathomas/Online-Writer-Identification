## ONLINE WRITER IDENTIFICATION WITH SPARSE CODING BASED DESCRIPTORS

The writer identification system focuses on assigning authorship of a handwritten document by using dynamic trace information such as coordinates and timestamps. It employs an allograph-based technique, where features are derived from strokes—continuous movements of a writing instrument on a surface. A dictionary is generated from these features, and sub-strokes are encoded using atoms from the dictionary to form a descriptor, which uniquely represents each document.
